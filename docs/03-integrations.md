확인 기준: **2026-11-01**. 업체 공식 문서와 공식 저장소를 읽고 정리했습니다.
설치·로그인·실제 호출 테스트는 수행하지 않았습니다. 요금과 제공 범위는 변경될 수 있습니다.

| 지금 필요한 일 | 우선 검토 | 선택 이유 |
|---|---|---|
| 사용하는 라이브러리의 API·버전별 예제 찾기 | Context7 | 개발 문서 검색에 초점 |

Context7와 Exa는 검색 대상이 다르고, Firecrawl과 Defuddle은 추출 범위가 다릅니다.
선택과 우선순위는 기능 문서를 바탕으로 한 판단이며, 도구 사이의 성능 비교 실험 결과는 아닙니다.

## 1. Context7: 라이브러리 문서 찾기

- **용도:** 프레임워크·라이브러리의 현재 문서, 사용 예제, 특정 버전의 API 확인.
- **적합한 작업:** Next.js 설정, SDK 호출 방법, 데이터베이스 클라이언트 문법 조사.
- **방식:** 라이브러리 이름을 식별한 뒤 관련 문서와 코드 예제를 가져옵니다.
- **인증:** Claude Code 플러그인은 브라우저 로그인. 수동 MCP 구성은 API 키도 지원합니다.
- **비용:** 무료 요금제가 있으며 확인 당시 월 1,000 API 호출을 포함했습니다. 초과 사용·팀·비공개 저장소 조건은 요금 문서를 확인하세요.
- **운영:** 공식 플러그인은 원격 MCP를 사용하므로 로컬 Node.js가 필요하지 않습니다. CLI 방식은 실행 환경이 필요합니다.
- **선택 기준:** 라이브러리 문서 확인이 잦으면 우선 검토합니다. 일반 뉴스·시장 조사 전체를 대체하는 도구로 보지는 않습니다.
- **중복:** 플러그인과 동일 서버 수동 등록을 함께 할 필요는 없습니다.

공식 자료: [Claude Code 연결](https://context7.com/docs/clients/claude-code), [인증·MCP 도구](https://context7.com/docs/resources/all-clients), [요금](https://context7.com/docs/plans-pricing).

## 2. Exa: 웹 검색과 출처 발견

- **용도:** 웹 검색, 알려진 URL의 본문 읽기, 여러 출처를 사용하는 조사.
- **적합한 작업:** 기술 비교, 관련 사례·공식 자료 탐색, 조사할 웹페이지 목록 만들기.
- **방식:** 기본 검색·본문 읽기 도구와 선택적 고급 검색 기능을 제공합니다.
- **인증:** 검색·fetch는 키 없이 제한된 무료 사용이 가능합니다. OAuth와 API 키도 지원합니다.
- **비용:** 인증된 사용은 자신의 팀 사용량·요금제에 귀속됩니다. 다단계 조사인 Exa Agent는 인증이 필요하고 사용량에 따라 과금됩니다.
- **운영:** 공식 호스팅 MCP와 Claude Code 공식 마켓플레이스 플러그인이 있습니다.
- **선택 기준:** 내장 웹 검색을 보완할 구체적인 필요가 있을 때 추가합니다.
- **한계:** 검색 결과나 에이전트 보고서는 원문 자체와 구분합니다. 중요한 결론에는 실제 원문을 확인합니다.

공식 자료: [Exa MCP·인증·도구·Claude Code 설치](https://exa.ai/docs/get-started/exa-mcp).

## 3. Firecrawl: 웹 수집과 문서 전처리

- **용도:** 웹 검색, 한 페이지 추출, 사이트 내 URL 발견, 여러 페이지 수집, 문서 파싱.
- **적합한 작업:** 공개 문서 사이트 수집, 웹페이지의 Markdown 변환, PDF를 지식 저장소에 넣기 전 전처리.
- **방식:** Scrape는 알려진 URL, Crawl은 여러 페이지, Parse는 PDF·문서 파일을 처리합니다.
- **출력:** Markdown·구조화 데이터 등을 제공하며 Parse는 페이지별 콘텐츠와 레이아웃 정보도 지원합니다.
- **OCR:** Parse는 이미지로 된 페이지에 OCR fallback을 지원합니다. 실제 표·수식·읽기 순서는 결과를 확인해야 합니다.
- **인증:** 제한된 keyless Search·Scrape·Parse, OAuth, API 키 방식을 제공합니다.
- **비용:** keyless는 일일 한도가 있고, 인증된 사용은 팀 요금제와 정책을 따릅니다. 무제한 무료 도구로 보면 안 됩니다.
- **운영:** 호스팅 MCP, 로컬 MCP 프로세스, 자체 호스팅 API는 서로 다른 구성입니다.

호스팅 서버는 사용자의 로컬 파일 경로를 직접 읽지 못합니다.
로컬 문서를 Parse에 보내려면 업로드 절차가 필요합니다. 공개 문서 URL은 Scrape로 처리할 수 있습니다.
로컬 MCP 프로세스를 실행해도 Firecrawl 클라우드 API에 연결하면 콘텐츠 처리는 외부에서 이루어집니다.
외부 전송을 피해야 하는 문서는 아래 Docling의 로컬 구성을 먼저 검토하세요.

공식 자료: [Claude Code 연결](https://docs.firecrawl.dev/quickstarts/claude-code), [인증 방식](https://docs.firecrawl.dev/mcp-server), [도구·파일 업로드](https://docs.firecrawl.dev/mcp-server/tools), [Parse](https://docs.firecrawl.dev/features/parse).

## 4. Defuddle: 일반 웹 기사의 본문 정리

- **용도:** 기사 형태의 HTML에서 본문을 추출해 읽기 쉬운 Markdown으로 준비.
- **적합한 작업:** 웹 기사 한두 개를 정리해 Obsidian에 보관하기 전 단계.
- **구분:** 지식 정리 플러그인과 별도로 설치·설정하는 외부 추출기입니다.
- **운영:** CLI는 URL·로컬 HTML·표준입력을 받아 정리된 HTML 또는 Markdown을 출력할 수 있습니다.
- **네트워크:** 공개 URL을 가져오는 경우 대상 사이트로 요청이 나갑니다. 로컬 실행이 곧 네트워크 없는 실행을 뜻하지는 않습니다.
- **한계:** PDF OCR, 로그인된 서비스의 완전한 수집, 모든 동적 페이지 처리를 보장하는 도구로 안내하지 않습니다.
- **선택 기준:** 일반 기사 정리만 필요하면 검토할 만합니다. 대량 수집·문서 파싱은 다른 도구의 범위입니다.

Defuddle은 외부 추출기이며 claude-obsidian에 설치 없이 내장되어 있다고 가정하지 않습니다.
일부 비동기 추출은 본문이 없는 페이지에서 외부 API로 보완할 수 있으므로 선택한 실행 옵션을 기준으로 데이터 흐름을 판단합니다.
공식 자료: [Defuddle 기능·CLI·출력·외부 서비스 설명](https://github.com/kepano/defuddle).

## 5. Docling: 로컬 PDF·OCR 전처리

- **용도:** PDF·스캔·오피스 문서 등을 읽고 Markdown 또는 구조화된 문서로 변환.
- **적합한 작업:** 로컬 논문·보고서·스캔 자료를 외부 문서 처리 서비스에 올리지 않고 전처리.
- **기능:** PDF 레이아웃·읽기 순서·표 구조 처리, OCR, Markdown·JSON 등 내보내기.
- **방식:** CLI·Python 라이브러리·MCP·서비스 형태를 제공합니다.
- **인증·비용:** 기본 로컬 도구는 오픈소스입니다. 외부 유료 API를 쓰지 않는 구성에서는 해당 API 요금이 없지만 로컬 연산 자원이 필요합니다.
- **운영:** Python과 선택한 OCR·모델 환경을 준비해야 하며, 초기 모델 다운로드가 필요할 수 있습니다.
- **라이선스:** 코드베이스는 MIT, 개별 모델은 해당 모델의 라이선스를 따릅니다.
- **한계:** 추출 결과를 원본과 대조합니다. 복잡한 표·수식·이미지의 완전한 보존을 보장하지 않습니다.

공식 자료: [Docling 공식 저장소·기능·설치 조건](https://github.com/docling-project/docling).

## claude-obsidian에 연결하는 방법

`claude-obsidian`의 지식 정리와 외부 자료의 텍스트 추출은 별도 단계입니다.
공식 README는 PDF 본문 추출·OCR과 웹 수집에 별도 도구나 실행 구성이 필요하다고 명시합니다.
실제 입력을 처리할 추출 도구가 연결되어 있는지 확인해야 합니다. [claude-obsidian의 현재 입력 지원 범위](https://github.com/AgriciDaniel/claude-obsidian#how-it-works)

권장 흐름은 다음과 같습니다.

1. Context7·Exa 등으로 필요한 출처를 찾거나 사용자가 제공한 원문을 선택합니다.
2. 웹 기사는 Defuddle·Firecrawl, PDF는 Docling·Firecrawl Parse 등으로 실제 텍스트를 추출합니다.
3. 추출 결과에서 제목·본문·표·코드·링크·페이지 누락 여부를 검토합니다.
4. 원문 URL 또는 파일 식별 정보, 수집 날짜, 추출 도구와 함께 Markdown을 준비합니다.
5. 선택한 vault의 `inbox/`에 전달하고 `wiki-ingest`의 원본 보존·검토 절차로 정리합니다.

| 연결에 관한 표현 | 정확한 의미 |
|---|---|
| Markdown을 통한 연결 가능 | 별도 도구의 추출 결과를 입력 자료로 전달할 수 있음 |
| 네이티브 자동 통합 | 플러그인 자체의 adapter·실행·저장 흐름을 구현하고 검증해야 하는 별도 사항 |
| 수집 완료 | 원문을 실제 가져왔고 추출 결과가 존재함 |
| 지식 저장 완료 | 원본·출처와 정리 결과가 선택한 vault에 실제 반영됨 |

이번 조사에서는 Firecrawl·Docling이 `claude-obsidian`에 자동 연결되는 구현이나 실제 동작을 검증하지 않았습니다.
“설치하면 웹·PDF가 자동으로 수집되고 기억된다”는 설명은 피해야 합니다.
원문을 추출한 Markdown도 오류나 누락이 있을 수 있으므로 원문 위치를 함께 보존하는 것이 좋습니다.

## 업무 서비스의 공식 MCP

아래 도구는 해당 서비스를 이미 사용하는 경우에 우선순위가 높습니다.
도구 자체의 요금, 연결한 서비스 요금, Claude Code 사용량은 구분해서 판단하세요.
공식 문서에 별도 MCP 요금이 명시되지 않았다는 사실만으로 모든 사용이 무료라고 단정하지 않습니다.

### Figma

- **업무:** 디자인 프레임·컴포넌트·변수·레이아웃을 구현에 활용하고 디자인 시스템과 코드를 연결.
- **권장 구성:** Figma 공식 플러그인은 MCP 설정과 Skills를 함께 제공합니다.
- **인증·운영:** Figma 계정 로그인. 원격 서버는 Figma 데스크톱 앱 없이 사용합니다.
- **비용 선택:** 요금제·좌석에 따라 읽기 도구 한도가 다릅니다. Starter/View/Collab의 한도는 유료 Full/Dev보다 작습니다.
- **추가 기능:** 캔버스 쓰기·UI 가져오기 등도 제공하지만 좌석·편집 권한·클라이언트 조건을 따릅니다.
- **선택 기준:** 팀이 Figma를 설계 기준으로 사용할 때 추가합니다. 화면을 자체 제작하는 모든 개발자에게 필수는 아닙니다.

공식 자료: [설치·인증](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/), [도구 개요](https://developers.figma.com/docs/figma-mcp-server/), [사용 한도](https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/).

### GitHub

- **업무:** 저장소·Issue·PR·Actions·보안 알림 등 개발 협업 정보를 읽고 작업에 반영.
- **인증:** 공식 Claude Code 원격 설치 문서는 PAT 방식을 안내합니다. 로컬 서버는 OAuth 로그인도 지원합니다.
- **운영:** GitHub 호스팅 원격 서버 또는 로컬 서버를 선택할 수 있습니다. Docker는 로컬 컨테이너 방식에 필요합니다.
- **권한:** toolset·개별 도구·읽기 전용 모드로 사용할 기능 범위를 줄일 수 있습니다.
- **비용 선택:** 계정·조직 정책과 연결된 GitHub 서비스 조건을 확인합니다. 이 문서에서는 MCP 별도 사용료를 확정하지 않습니다.
- **선택 기준:** Issue→구현→PR 흐름이나 여러 저장소 조사에 유용합니다. 기존 `gh` CLI로 충분하면 추가 우선순위를 낮출 수 있습니다.

공식 자료: [공식 저장소](https://github.com/github/github-mcp-server), [Claude Code 인증·설치](https://github.com/github/github-mcp-server/blob/main/docs/installation-guides/install-claude.md).

### Linear

- **업무:** 이슈·프로젝트·댓글을 찾아 요구사항을 파악하고 개발 진행 상황을 연결.
- **인증:** OAuth 2.1 또는 API 키. 공식 호스팅 서버를 사용합니다.
- **권한:** 기본 endpoint는 읽기·쓰기를 제공합니다. 읽기 전용 endpoint나 read 범위 인증도 선택할 수 있습니다.
- **비용 선택:** Linear 계정·워크스페이스 권한과 요금제 조건을 확인합니다. 확인한 MCP 문서에서는 별도 MCP 요금을 확정할 수 없었습니다.
- **선택 기준:** 업무의 기준이 Linear일 때 추가합니다. GitHub Issues만 사용하는 프로젝트에는 우선순위가 낮습니다.
- **현재 연결 방식:** 신규 설정은 Streamable HTTP `/mcp`를 사용하며 `/sse`는 과거 클라이언트용 fallback입니다.

공식 자료: [Linear MCP·Claude Code·권한](https://linear.app/docs/mcp).

### Sentry

- **업무:** 운영 오류 검색, 이슈 분석, 성능 데이터 조사, 프로젝트 관련 맥락 확인.
- **인증:** OAuth로 Sentry 계정에 연결합니다.
- **운영:** 원격 서버를 조직 또는 프로젝트 단위로 제한할 수 있으며 공식 문서는 가능하면 프로젝트 범위를 권장합니다.
- **비용 선택:** 기존 Sentry 계정과 데이터 접근 범위가 필요합니다. MCP 연결과 Sentry 제품의 요금·기능 제공 범위는 구분합니다.
- **선택 기준:** 이미 Sentry로 운영 문제를 추적하며 로그와 코드 사이를 자주 오가는 경우 유용합니다.

공식 자료: [Sentry MCP·범위 설정·Claude Code](https://mcp.sentry.dev/).

### Supabase

- **업무:** 프로젝트·DB 스키마·쿼리·로그·개발 관련 정보를 확인하고 Supabase 작업을 지원.
- **인증:** 일반 원격 연결은 브라우저 OAuth를 사용하며 PAT가 필수는 아닙니다.
- **운영:** 프로젝트 범위를 지정하고 필요한 기능 그룹을 선택할 수 있습니다. 읽기 전용 옵션도 제공합니다.
- **비용 선택:** 기존 Supabase 프로젝트와 서비스 요금·기능 제한을 확인합니다. MCP 사용이 DB 자원·유료 기능을 무제한으로 제공하는 것은 아닙니다.
- **선택 기준:** Supabase를 실제 백엔드로 쓰는 프로젝트에서 추가합니다. 모든 데이터베이스 작업을 위한 범용 필수 도구는 아닙니다.
- **중복:** 공식 MCP와 Skills를 묶은 플러그인도 있으므로 동일 서버를 두 번 등록하지 않도록 구성합니다.

공식 자료: [Supabase MCP·인증·프로젝트 범위](https://supabase.com/docs/guides/ai-tools/mcp).

## 용도별 작은 조합

| 작업 형태 | 시작 조합 | 필요할 때 추가 |
|---|---|---|
| 일반 개발 | Context7 | GitHub 또는 실제 사용하는 업무 MCP |
| 디자인 기반 프런트엔드 | Context7 + Figma | 브라우저 검증 도구 하나 |
| 자료 조사와 Obsidian 정리 | Exa + claude-obsidian | 원문 추출이 부족하면 Firecrawl 또는 Defuddle |
| PDF·스캔 중심 지식 정리 | Docling + claude-obsidian | 공개 웹 자료 수집이 필요하면 Exa·Firecrawl |
| 운영 문제 해결 | GitHub + Sentry | 사용하는 DB가 Supabase면 Supabase MCP |

설치 수보다 실제 반복 작업을 줄이는지가 선택 기준입니다. 이미 있는 기능과 겹치면 하나를 먼저 사용해 보고 확장하세요.
